# NEET Practice Lab Android starter

This is a starter Android WebView app with a small sample question set. It is not a complete 180-question app yet. The sample questions are for demonstrating the build process; add and review a full question bank before using it for exam preparation.

## Build on GitHub
1. Create a repository and upload the contents of this folder, including the hidden `.github` folder.
2. Open Actions → Build Android APK → Run workflow.
3. Download the `NEET-Practice-Lab-debug-APK` artifact from a successful run and extract `app-debug.apk`.
